# coast/ (Python package)

The Python package contains the API (`api/`), conductor flows
(`conductor/`), guest agent (`agent/`), console proxy (`console/`), and
heartbeat and failover service (`health_manager/`). Drivers live in
`drivers/`; shared utilities, database access, versioned objects, policies
and networking helpers live in `common/`, `db/`, `objects/`, `policies/`
and `network/`. Service entry points are in `cmd/`, and tests in `tests/`.
Specs: `doc/source/`.
